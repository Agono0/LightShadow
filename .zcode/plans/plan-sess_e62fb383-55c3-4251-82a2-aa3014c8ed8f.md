## A. P0 bug fixes (code)

1. **Reversed controls / broken camera after being caught** — root cause: `CinematicDirector.PlayShotRoutine` (`Scripts/Systems/CinematicDirector.cs:79-102`) enables the Cinemachine brain on the real camera but **never restores the camera transform** (the shot cam faces ~180° away; movement is body-relative → "reversed"), and if the reflection-based `EnableBrain` fails the brain stays enabled forever (camera hard-stuck). Fixes:
   - Snapshot `main.transform.localPosition/localRotation` before enabling the brain; restore in a `finally` (and on the brain-null path).
   - Re-fetch the brain for handback instead of trusting `EnableBrain`'s return.
   - New `PlayerController.RespawnReset()` (zero `pitch`, camera local pose → identity, clear `crouchToggle`, `ExternalInputLocked = false`, re-lock cursor), called from `GameManager.WakeAtCheckpoint` (`Scripts/Core/GameManager.cs:254-260`).
   - Spawn rotation: lit zones are stored with identity rotation (`LitZone.cs:76`, `SceneBuilderScenes.cs:520-524`) so the player always wakes facing world +Z. Give each lit zone a yaw facing its room in the builder.
2. **FPS counter not showing** — `FpsCounter`/`FpsText` is in the builder (`SceneBuilderUI.cs:169-175`) but in **zero shipped scenes** (scene snapshot predates the builder change) and `FpsCounter.RefreshVisibility` (`FpsCounter.cs:69`) disables the component, which permanently unsubscribes it from `GameSettings.Changed`. Fixes: only toggle the label's `gameObject`, never `enabled`; rebuild all scenes; verify `f3a3a049253015b42a801fddf5e3881c` occurs in 02_School.unity after rebuild.
3. **Mouse escapes the window** — no `OnApplicationFocus` anywhere; cursor locks only in `PlayerController.Start`. Add a focus-regain re-lock + a throttled per-frame guard in `PlayerController` (desktop only, suppressed while pause/quiz/dialogue is open — existing `ExternalInputLocked`/`PauseMenu.IsOpen`/`quizUI.IsOpen` states already cover this).

## B. Audio — replace all synthesised sound with real CC0 files

Seam found: `ProceduralSfx` is a static class with 5 lazy clip properties (`Correct/Wrong/Click/Pickup/Power`) whose call sites do `if (clip == null) clip = ProceduralSfx.X;` — perfect for a library-first fallback pattern. `AmbientDrone.BuildClip()`, `ShadowAudio` (per-FSM-state clips), `AdaptiveMusic` (3 procedural layers) follow the same shape. `.gitattributes` already routes `*.ogg`/`*.wav` via LFS. No footstep sounds exist at all — add them.

1. **Download CC0 packs** (Kenney Interface/Impact/Digital Audio — direct zips; OpenGameArt CC0: horror ambience loop, footstep set, ghost growls/whispers; optionally music stems): extract into `Assets/ThirdParty/<pack>/` with license files, log every URL in `Docs/ASSET_LICENSES.md`.
2. **New `AudioImportTool.cs`** (Tools/Editor): copies needed clips to `Assets/_Project/Audio/{SFX,AMB,Music}/` with convention names (`SFX_QuizCorrect/Wrong/Click/Pickup/Power/Footstep1-4`, `AMB_SchoolNight`, `SFX_ShadowGrowl/Stalk/Chase/Repelled`, `MUS_Calm/Tension/Pulse`), sets import settings (loop on AMB, compression), and builds `AudioLibrary.asset` (ScriptableObject with named clip fields).
3. **Runtime seam**: `SfxLibrary` static registry populated by a builder-wired bootstrap; `ProceduralSfx`/`AmbientDrone`/`ShadowAudio`/`AdaptiveMusic` check it first, synthesis stays as fallback (nothing breaks if a file is missing). Names route through the existing `VolumeCategories` convention (MUS_/AMB_/SFX_/UI_).
4. **New `Footsteps.cs`** (Player): speed-timed steps, 2–4 surface variations, crouch/sprint volume; wired by `SceneBuilderPrefabs`.
